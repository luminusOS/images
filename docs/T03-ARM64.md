# T03: Fedora 45 ARM64 UEFI proof

This proof-only workflow uses T03-specific immutable Fedora 45 ARM64 pins. It
does not change the production digest in `config/versions.env` or publish an
image or package. The bootc image is pinned to
`sha256:3c7cf18e9b1eb23d65cdaec7c5d15e8b4d12849ec20f61dba02ac3e3293f66d1`
(Fedora 45.20261019.1, kernel 7.2.11-300.fc45.aarch64). The Fedora 45 builder
is pinned to `sha256:54fe92a655ebbcec468dc6fa953c0d1d2b474630a72f953702766c8389dd1a15`.
These prototype pins do not change production defaults.

The workflow builds a small qcow2 and boots it on a native ARM64 GitHub-hosted
runner through AArch64 UEFI in QEMU. Its derived bootc image carries an explicit
GPT, EFI, ext4 boot, and ext4 root layout for Image Builder.

The job only runs for the public repository on
`proof/t03-arm64-uefi`. It can start from a push to that exact branch or a
manual dispatch selected on that branch. It has read-only repository
permissions, uses the standard public ARM runner, and retains its evidence for
one day. QEMU uses `-cpu host` with KVM and `-cpu max` with bounded TCG. The
qcow2 is used only on the disposable runner; the workflow records its SHA-256
and virtual/physical file sizes, then deletes it. The artifact contains logs
and metadata only. It excludes the disk image, an ISO, an OCI image, and
packages.

The guest writes a start marker with a fresh per-run nonce, then checks `aarch64`,
Fedora 45, and `/sys/firmware/efi` before writing the matching pass marker.
A complete serial transcript is required;
the host architecture, QEMU exit status, and build image architecture are also
checked, and an early QEMU exit fails. The evidence artifact contains the serial
proof, QEMU diagnostics, disk hash and sizes, concise runner/build metadata, and
a build log capped at 1 MiB. The boot proof has not yet run on the hosted ARM
runner. It does not qualify a final ISO, GNOME, Sirius, or an installation
flow.

Run the local checks with:

```bash
python -m unittest discover -s tests -p 'test_t03_arm64_proof.py' -v
bash -n .github/scripts/t03-arm64-proof.sh
```

The host build/boot itself requires a native ARM64 machine and is intentionally
not emulated on x86. The runner inventory and public-repository pricing are
documented by [GitHub](https://docs.github.com/en/actions/reference/runners/github-hosted-runners).
Image Builder's bootc qcow2 input and configuration behavior are documented
[here](https://osbuild.org/docs/user-guide/image-descriptions/bootc/qcow2/) and
[here](https://osbuild.org/docs/developer-guide/projects/image-builder/advanced/bootc/sources-of-configuration/).
Podman's storage configuration is documented
[here](https://docs.podman.io/en/stable/markdown/podman.1.html#environment-variables).
